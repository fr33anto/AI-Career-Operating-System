# UI/UX
Indonesian default + English switch. UI language independent of document output language. Responsive/mobile-friendly. Primary CTA: `+ Analyze Job`. Show summary first, details on demand. Generated CV/letter remain editable drafts. Every async screen has loading/empty/success/error states.

MVP pages: Landing, Google login, Onboarding, Dashboard, Job Input, Job Result, Match, CV Editor, Cover Letter, Interview Prep, Applications, Career Passport, Billing, Account, Admin.
